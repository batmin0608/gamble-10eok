# 십억 카지노

100만 원으로 시작해서 10억을 모으는 웹 도박 게임이에요. 가상 머니만 쓰고 실제 돈은 오가지 않아요.

- 게임: 룰렛, 하이로우, 폭탄 상자, 슬롯, 인디언 포커(1:1 대결)
- 파산하면 공사장 미로를 탈출해야 100만 원을 받고 다시 시작할 수 있어요.
- 인디언 포커 온라인 대결은 Firebase로 연결돼서 **로그인 없이 링크만으로** 친구와 겨룰 수 있어요.

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 게임 전체 |
| `firebase-config.js` | Firebase 연결 설정 (직접 채워야 해요) |
| `database.rules.json` | Firebase 보안 규칙 (콘솔에 붙여 넣어요) |

Firebase 설정이 없어도 다른 게임과 AI 대결은 모두 돼요. 온라인 대결만 열리지 않아요.

## 설정 순서 (처음 한 번, 10분 정도)

### 1. Firebase 프로젝트 만들기
1. https://console.firebase.google.com 에 구글 계정으로 들어가요.
2. **프로젝트 추가**를 누르고 이름을 정해요(예: `gamble-10eok`). Google 애널리틱스는 꺼도 돼요.

### 2. 익명 로그인 켜기
플레이어는 아무것도 입력하지 않지만, 보안 규칙이 사람을 구분하려면 이게 필요해요.
1. 왼쪽 메뉴 **빌드 → Authentication → 시작하기**
2. **로그인 방법** 탭에서 **익명**을 골라 **사용 설정** 후 저장

### 3. Realtime Database 만들기
1. 왼쪽 메뉴 **빌드 → Realtime Database → 데이터베이스 만들기**
2. 위치는 아무거나 괜찮아요(가까운 곳: `asia-southeast1` 싱가포르).
3. **잠금 모드로 시작**을 고르고 사용 설정
4. 생성되면 맨 위에 보이는 주소(`https://....firebasedatabase.app`)를 복사해 두세요. 이게 `databaseURL`이에요.

### 4. 보안 규칙 넣기
1. Realtime Database 화면의 **규칙** 탭을 열어요.
2. 안에 있는 내용을 모두 지우고 `database.rules.json` 파일 내용을 통째로 붙여 넣은 뒤 **게시**해요.

### 5. 웹 앱 등록하고 설정값 복사
1. 왼쪽 위 톱니바퀴 → **프로젝트 설정** → 아래쪽 **내 앱**에서 웹 아이콘(`</>`)을 눌러요.
2. 앱 이름을 정하고 등록해요. Firebase 호스팅은 체크하지 않아도 돼요.
3. 화면에 나오는 `firebaseConfig`의 값들을 `firebase-config.js`의 같은 자리에 옮겨 적어요. `databaseURL`이 안 보이면 3단계에서 복사한 주소를 넣으면 돼요.

### 6. 승인된 도메인 추가
1. **Authentication → 설정 → 승인된 도메인**에서 **도메인 추가**
2. `내아이디.github.io`를 넣어요 (GitHub 사용자 이름이 `kim`이면 `kim.github.io`).

### 7. GitHub Pages로 공개
1. GitHub에서 새 저장소를 만들어요(예: `gamble-10eok`, Public).
2. `index.html`, `firebase-config.js`, `database.rules.json`, `README.md`를 올려요.
3. 저장소의 **Settings → Pages**에서 Source를 **Deploy from a branch**, Branch를 `main` / `(root)`로 정하고 저장해요.
4. 1~2분 뒤 `https://내아이디.github.io/gamble-10eok/` 주소로 게임이 열려요. 이 링크를 친구에게 보내면 끝이에요.

## 대결하는 법
1. 둘 다 게임 링크를 열고 **도박장 입장 → 인디언 포커**로 가요.
2. 한 명이 **방 만들기**를 누르면, 다른 사람 화면의 "사람과 대결" 목록에 그 방이 떠요. **입장**을 누르면 바로 시작해요.
3. "내 이름" 칸에 이름을 적어 두면 상대 화면에 그 이름이 보여요.

## 알아 둘 점
- **지갑(자산)은 각자 브라우저에 저장돼요.** 다른 기기나 다른 브라우저로 들어가면 100만 원부터 새로 시작해요.
- **카드는 상대가 대신 뽑아 줘요.** 내 카드는 상대 브라우저가 뽑아서 서버에 올리고, 보안 규칙 때문에 판이 끝나기 전에는 나도 읽을 수 없어요. 그래서 개발자 도구로 자기 카드를 훔쳐볼 수 없어요. 다만 돈 계산은 각자 브라우저에서 하기 때문에, 작정하고 코드를 고치면 속일 수는 있어요. 친구끼리 즐기는 용도예요.
- 두 사람이 완전히 같은 카드(숫자와 무늬 모두)를 받으면 판돈을 반씩 나눠요. 확률은 52분의 1이에요.
- 대결 도중 창을 닫으면 기권으로 처리되고, 건 돈을 잃어요.
- Firebase 무료 요금제(Spark)로 충분해요. 동시 접속 100명, 저장 1GB까지 무료예요.
